# OP-XY: sintes propios

Sintes para el OP-XY, como motores de [Open-XY](https://github.com/etcetc000/open-xy). Todo es gratuito y libre.

| Sinte | Qué es |
|---|---|
| [Twin Osc](twinosc) · [probar](https://jjaimeros.github.io/op-xy-color-synths-things/twinosc/docs/) | Sinte de dos osciladores |
| [Nuvola](nuvola) · [probar](https://jjaimeros.github.io/op-xy-color-synths-things/nuvola/docs/) | Sinte de nubes: hasta 5 osciladores al unísono |
| [Acidgun](acidgun) · [probar](https://jjaimeros.github.io/op-xy-color-synths-things/acidgun/docs/) | Bajo ácido al estilo TB-303 con una pistola de rayos |
| [Ofender](ofender) · [probar](https://jjaimeros.github.io/op-xy-color-synths-things/ofender/docs/) | Chiptune con una cabina arcade y un matamarcianos que juega solo |
| [Raver](raver) · [probar](https://jjaimeros.github.io/op-xy-color-synths-things/raver/docs/) | Supersaw para sonidos de rave, con láseres |
| [`sdk-patch/`](sdk-patch) | Parches para Open-XY v0.0.5: carretes de cinta animados, y estado de play y tempo en las pantallas |

Para compilar, clona Open-XY v0.0.5 al lado de este repositorio y aplica los parches. Cada carpeta tiene su README y su licencia.
